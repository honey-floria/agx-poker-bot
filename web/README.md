# 可交互浏览器牌桌

本目录包含一个零依赖、完全在浏览器本地运行的六人无限注德州扑克牌桌，比赛结构按照 AGX 的240手复式赛制设计。

## 启动

```bash
cd web
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。

公开版本：[AGX Poker Lab](https://agx-poker-lab.rockyfinch129.chatgpt.site)

## 比赛结构

- 真人控制一个固定参赛者，五个浏览器本地 AI 控制其余参赛者。
- 每场比赛共240手，分为六轮，每轮40手。
- 每手所有参赛者重新获得10,000筹码。
- 六轮重复使用相同的40组物理牌序和按钮位置。
- 六名固定参赛者依次坐遍六个物理座位。
- 最终按照固定参赛者编号的累计整数净额排名。

## 当前能力

- 支持翻前、翻牌、转牌和河牌；
- 支持弃牌、过牌、跟注、下注、加注和全下；
- 支持隐藏底牌、边池、摊牌和平分底池；
- 显示比赛进度、当前阶段、阶段内手数、动作记录和累计净额；
- 牌局数据不会发送到网络。

## 当前限制

网页中的五个 AI 使用 `web/app.js` 内的浏览器专用简化策略，目前还没有直接调用根目录的正式 `submission.js`。正式 AI 接入、完整 AGX 计分规则和连续240手自动化测试已经记录在根目录的 [TODO.md](../TODO.md) 中。
