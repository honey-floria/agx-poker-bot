# NoRegrets 离线教师方法与合规说明

本项目拟使用公开的 NoRegrets 源码在离线环境自行训练六人 100BB 蓝图，再把教师的动作概率蒸馏成满足 AGX 限制的纯 JavaScript 学生。最终提交不包含 NoRegrets 运行时，不访问网络或外部模型文件，也不启动求解器。

审计固定的是公开仓库 `https://github.com/conorarmstrong/noregrets.git` 的 commit `757f7692738069522195d2b486eec60a8b010c0c`（获取日期 2026-10-20）。该版本使用 MIT 许可证；许可证副本与文件哈希保存在 `poker-distill/teachers/noregrets/`。公开 README 同时说明：公开版约滞后私有开发版十二个月，预训练蓝图与其他预训练产物不公开、另按商业许可提供。本项目只使用公开源码自行生成的产物，禁止使用或暗示拥有商业蓝图、私有源码、泄漏权重或官方 Pluribus 权重。

“Pluribus 风格”“NoRegrets”或“CFR”只描述方法来源，不构成 GTO 或强度声明。教师和学生强度必须通过项目门禁与配对评测证明。

用户已于 2026-10-20 确认主办方允许“用公开源码训练离线教师”。确认的问题为：

项目清单记录该确认；部署限制仍保持不变。许可证审计只说明公开源码许可条件，不替代法律意见。

上游 checkout 保持 detached、只读和干净；当前没有上游源码修改。将来若确需补丁，必须以独立 patch 文件记录原始 commit、理由、diff 哈希和适用命令；AGX 映射、查询导出和验证逻辑一律放在 `tools/noregrets/`。
