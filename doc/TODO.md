## 发布验收标准

一个新 AI 版本只有同时满足以下条件，才应替换当前正式版本：

- [ ] 静态校验通过。
- [ ] 所有牌型与合法动作测试通过。
- [ ] 没有非法下注额。
- [ ] QuickJS 最坏动作耗时低于平台限制并保留安全余量。
- [ ] 多个随机种子和多个对手种群下的结果没有明显退化。
- [ ] 成对牌局的平均净额或第一名率达到预先设定的提升门槛。
- [ ] GitHub、SSH服务器和待上传文件的提交版本完全一致。

## 当前已知限制

- Python 模拟器仍是近似模型；Node.js 直接模拟器已经执行 `submission.js`，但仍不能替代 AGX 私有引擎的最终评测。
- 网页中的五个 AI 仍使用浏览器专用简化策略，不是正式 `submission.js`。
- 本地性能数据来自 Node.js，不能完全代表 AGX QuickJS 的执行时间。
- 当前范围加权和EV模型属于近似模型，不是完整博弈论均衡求解器。
- 公开排行榜、天梯分、胜率和作废局处理属于平台层能力，当前项目只实现了部分本地比赛结算。
